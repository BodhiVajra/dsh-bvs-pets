# 桌宠素材工艺标准（VP9-alpha 透明视频路线）

> 目标：AI 生成 → 透明动画 → 交给 `dsh-mypet` 插件直接播放。
> 最终格式：**WebM 容器 + VP9 编码 + `yuva420p`（带 alpha 通道）**，透明背景、无缝循环。
> 本文件只定「工艺标准」，不教 AI 工具的具体用法（各家工具界面不同）。

---

## 一、角色立绘规格（AI 生图用）

| 项 | 标准 |
|---|---|
| 画幅 | 正方形，**≥ 1024×1024，建议 2048×2048** |
| 构图 | **Q 版 / 半身大头**（挂件最终显示约 120~200px，大头小身子才看得清表情） |
| 背景 | **纯绿 `#00FF00`** 或**纯品红 `#FF00FF`**；能直接出 **PNG 透明背景** 最好 |
| 姿态 | 正视图 + 四肢完整；角色四周留 **10~15% 呼吸空间**，避免肢体贴边被裁 |
| 一致性 | 所有帧/动作用**同一段角色描述 + 同一 seed**，保证是同一个角色 |

> AI 生成最容易翻车的是「换个动作就换一张脸」。锁定角色描述后，所有后续生成都复用同一段 prompt。

---

## 二、动画生成三条路径（选一条）

| 路径 | 做法 | 可靠性 | 建议 |
|---|---|---|---|
| **① 逐帧透明 PNG 序列** | AI 生成逐帧透明 PNG（同角色、逐帧微动）→ 合成视频 | 最稳 | **首选**（抠像干净、可控） |
| **② 绿幕视频抠像** | AI 生成绿幕视频 → chroma key 抠绿 → 得 alpha | 中 | 视频模型不支持透明输出时用 |
| **③ 原生透明视频** | 视频模型直接输出带 alpha（部分模型支持） | 看工具 | 有就最省事 |

> 用的模型**没有透明/绿幕输出**时，退回路径①或②，别硬上。

---

## 三、视频成品规格

| 项 | 标准 |
|---|---|
| 容器 | `.webm` |
| 编码 | **VP9**，像素格式 **`yuva420p`**（带 alpha） |
| 分辨率 | **512×512**（或 640×640） |
| 帧率 | 24 或 30 fps |
| 时长 | 2~5 秒/段 |
| 循环 | **首尾帧衔接 = 无缝循环** |
| 背景 | 完全透明，无黑边 |

---

## 四、动作清单（最小集，先做这 3 个）

| 文件名 | 动作 | 用途 | 时长 | 循环 |
|---|---|---|---|---|
| `idle.webm` | 待机 | 默认呼吸/眨眼 | 3s | 无缝循环 |
| `click.webm` | 点击回应 | 被点一下（开心/惊讶） | 1.5s | 单次，播完回 idle |
| `drag.webm` | 拖拽中 | 被拎起来 | 3s | 循环 |

> 后续可选：`sleep.webm` 休息、`happy.webm` 开心、`move.webm` 移动。先别做多，3 个验证够用。

---

## 五、ffmpeg 转码命令（标准写法）

```bash
# ① 逐帧透明 PNG → VP9-alpha webm（最常用）
ffmpeg -framerate 24 -i frame_%04d.png \
  -c:v libvpx-vp9 -pix_fmt yuva420p -crf 30 -b:v 0 -row-mt 1 idle.webm

# ② 绿幕视频 → 抠像 → VP9-alpha webm（绿屏参数按实际微调）
ffmpeg -i input.mp4 -vf "chromakey=0x00FF00:0.1:0.2" \
  -c:v libvpx-vp9 -pix_fmt yuva420p -crf 30 -b:v 0 output.webm

# ③ 已带 alpha 的 mov(HEVC-alpha) → webm
ffmpeg -i input.mov \
  -c:v libvpx-vp9 -pix_fmt yuva420p -crf 30 -b:v 0 output.webm
```

> `-b:v 0` + `-crf` 让 VP9 走恒定质量（否则默认按码率跑会糊）。
> 无缝循环可能还要加 `-auto-alt-ref 0`，最终参数以本地实测为准。

## 六、交付命名/目录约定

生成好的 webm 直接放进：

```
dsh-mypet/assets/
├─ idle.webm
├─ click.webm
└─ drag.webm
```

- 文件名**小写英文**、固定为上面三个，插件按名加载。
- 替换素材**不用改代码**，覆盖同名文件后刷新页面即可。

## 七、常见坑（生成时对照自查）

1. **黑底**：不是 `yuva420p` / 没带 alpha，播出来是黑方块。
2. **循环跳帧**：首帧 ≠ 末帧的接续姿态，循环时明显顿一下。
3. **角色不一致**：换了 prompt/seed，动作之间像两个人。
4. **分辨率过低**：<512 缩放放大后糊；过大则文件体积暴涨。
5. **抠像脏边**：绿幕边缘残留绿边/毛边，抠像参数没调干净。
